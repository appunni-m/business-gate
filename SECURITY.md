# Security and safety reports

Version 0.1.0 is a development build with connected-app actions disabled. No supported production integration or private security contact has been published yet. The owner must establish a private reporting channel before public distribution.

Do not put phone numbers, messages, account credentials, private screenshots, UI trees, or signing keys in public issues. Until a private channel exists, request contact from the repository owner with a non-sensitive description only.

Wrong-person changes, false verified results, receiver confusion, and any send/report/delete action are release-stopping defects. Keep the adapter inactive, preserve local choices, and reproduce with consenting synthetic test accounts. There is no remote kill switch or automatic upload mechanism.
